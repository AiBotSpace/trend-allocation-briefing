# 趋势与全天候配置简报

每日 A 股趋势信号、市场情绪与全天候配置对照。事实、推断、未知严格分开；
所有数字须有可核对的公开来源，未核实处标注未知，不编造价格或回报。

## 交付

- 每期一份新的 Google Doc（旧版保留不覆盖），链接见 `state.json`。
- 工作日（周一至周五）早上 9:00（北京时间）发送。
- 同步渠道：本聊天（链接 + 摘要）、飞书（完整版全文）、Telegram（完整版全文，分段发送）。
- 节假日休市跳过，周末不发送（无新交易数据）。

## 目录

- `generator/` —— 每期简报的 python-docx 生成器（`gen_briefing_NN.py`）与纯文本提取器（`extract_text.py`）。
- `editions/` —— 每期简报的完整纯文本版（`briefing-NN.txt`）与 Telegram 分段（`briefing-NN.chunkN.txt`）。
- `state.json` —— 系列状态：上期点位、回报、情绪基线、趋势系统信号、未解决的未知项。
- `docs/cron-job.md` —— 定时任务说明（日程与执行步骤）。

注：`.docx` 排版稿与渲染校验文件不在仓库中（GitHub 连接器仅推送 UTF-8 文本）；
排版版以 Google Doc 为准，内容与 `editions/` 的纯文本版一致。

## 简报结构（每期固定）

结论（前置）→ 事实（A股指数表、市场情绪、近期调整对照、外围与宏观）→
全天候参考组合对照 → 趋势系统与仓位 → 推断 → 未知 → 本周关注 → 数据来源。

## 全天候参考组合（公开口径，非个人持仓）

股票 30%／长期债券 40%／中期债券 15%／黄金 7.5%／大宗商品 7.5%。
股票锚定沪深300，债券锚定中国国债，黄金与商品锚定国际期货报价。

## 趋势系统（规则固定，每期沿用同一口径）

- 趋势过滤：指数收盘价 vs MA20／MA60／MA250（年线）。
- 趋势强度：价格在 52 周高低区间中的位置；近 1 月／近 6 月涨跌幅。
- 广度确认：上涨家数占比、站上 MA20 的 ETF 占比、涨停－跌停差。
- 波动率环境：VIX 及近期振幅。

仓位映射（A股权益仓位，占总资产；参考权重 30% 为满配基准）：
强多头 25%–30%／偏多 15%–25%／中性 10%–15%／偏空 5%–10%／防御 0%–5%。
仓位建议为规则系统的信号输出，非个性化投资建议。

## 新一期的生产流程

1. 读 `state.json`，了解上期基线；只写变化与新增信号。
2. 检索最近一个完整交易日的公开市场数据（指数、情绪、趋势、利率汇率、商品、事件）。
3. 复制上期生成器为 `gen_briefing_NN.py`，更新内容，生成 `editions/briefing-NN.docx`，
   转 PDF 逐页检查渲染。
4. 创建新 Google Doc 并上传转换，读回验证。
5. `extract_text.py` 生成纯文本版与 Telegram 分段。
6. 更新 `state.json`，同步发送三处，推送本仓库。
